# Generator data

`hr-v1.jsonl` contains the 124 Hadamard-reduced groups HR001-HR124 used by the
TCL6 evaluator. `cc-v1.jsonl` contains the 40 connected cumulative-correlation
terms from which they are derived.

The matching JSON schemas describe the record format. `manifest.json` lists
the notation, integration domains, and source references.

See `docs/conventions.md` in the source distribution for coupling and
normalization conventions.
